# Project Rules & Constraints

## Testing & Verification Guidelines
- **Leave Testing to the User:** Do NOT run `browser_subagent`, automated browser testing, or interactive browser sessions for UI testing.
- **User-Led Verification:** The user will perform all manual visual inspections, browser testing, and feature verifications in their own browser.
- **Agent Responsibility:** Complete code changes, ensure static code/syntax validity, and hand off testing and review directly to the user.
